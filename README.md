# أرشيف القاهرة: قضايا الليل

لعبة تحقيق واستبعاد تفاعلية بالمصري. ١٢ قضية بتتحل بالترتيب: كل قضية فيها مشتبه فيهم وأدلة بتتكشف بالتدريج أثناء التحقيق، وفي الآخر بتوجّه اتهامك وتشوف هل قبضت على الجاني الصح ولا لأ.

**جرّب اللعبة من هنا:** https://cairo-archive.vercel.app

## المميزات

- ١٢ قضية كاملة بأجواء مصرية، من «أسورة الهانم» لـ«نوبة السقيا»، بتتفتح واحدة ورا التانية.
- حسابات حقيقية بالإيميل: تسجيل دخول، استرجاع كلمة السر، وتقدّم كل لاعب بيتحفظ في حسابه ويكمّل من أي جهاز.
- نظام رتب للمحققين: محقق مبتدئ ← محقق متمرّس ← كبير المحققين، حسب اللي حليته ودقة اتهاماتك.
- تايمر للتحقيق وجدول أدلة، وملف (دوسييه) لكل مشتبه فيه فيه صورته وبياناته، ودفتر ملاحظات أثناء اللعب.
- موسيقى تصويرية: «Mysterioso March» — Kevin MacLeod، مرخّصة CC BY 4.0.
- واجهة عربي (RTL) بالكامل، مع دعم تقليل الحركة (prefers-reduced-motion).

## التكنولوجيا

- React 18 + TypeScript + Vite 5
- Supabase للمصادقة وقاعدة البيانات (محمية بسياسات Row Level Security — مفيش أي مفاتيح سرية في الكود)
- الاستضافة على Vercel

## التشغيل على جهازك

المتطلبات: Node.js نسخة 18 أو أحدث.

```bash
npm install     # أول مرة بس
npm run dev     # يفتح اللعبة على http://localhost:5173
```

الواجهة بتقرأ إعدادات الاتصال بـ Supabase من `src/lib/supabase.ts`. المفتاح الموجود publishable وآمن يظهر في المتصفح، لكن لو عايز تشغّل نسخة مستقلة ببياناتك، اعمل مشروع Supabase خاص بيك وحط قيمك مكان الموجودة.

لبناء نسخة النشر:

```bash
npm run build   # يطلع الموقع الجاهز في فولدر dist/
npm run preview # معاينة النسخة المبنية محليًا
```

## تنظيم الكود

- `src/game/cases.ts` — محتوى القضايا الـ١٢: القصة، المشتبه فيهم، الأدلة، ونصوص الحل.
- `src/game/engine.ts` — منطق الجولة: التايمر، جدول الأدلة، التقييم، الحفظ والاستكمال.
- `src/game/audio.ts` — التحكم في الموسيقى.
- `src/components/` — الشاشات: الدخول والتسجيل، الأرشيف، اللعب، النتيجة، والهيكل العام.
- `src/photos/` — الصور محلية جوه المشروع.
