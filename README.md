# أرشيف القاهرة: قضايا الليل — القضية الأولى «أسورة الهانم»

لعبة تحقيق تفاعلية بـ React + Vite + TypeScript. النسخة دي فيها القضية الأولى قابلة للعب كاملة، وباقي القضايا ظاهرة مقفولة في الأرشيف.

## التشغيل على جهازك

المتطلبات: Node.js نسخة 18 أو أحدث (من nodejs.org).

```bash
npm install     # أول مرة بس
npm run dev     # يفتح اللعبة على http://localhost:5173
```

## بناء نسخة النشر

```bash
npm run build   # يطلع الموقع الجاهز في فولدر dist/
npm run preview # معاينة النسخة المبنية محليًا
```

## النشر على موقع (مجانًا)

بعد `npm run build`، فولدر `dist/` فيه الموقع كامل (HTML/CSS/JS/صور). ارفعيه على أي استضافة ملفات ثابتة، مثلًا:

- **Netlify**: اسحبي فولدر dist على app.netlify.com/drop
- **Vercel**: `npx vercel dist`
- **GitHub Pages**: ارفعي محتوى dist على فرع gh-pages
- أي استضافة عادية بـ cPanel: ارفعي محتوى dist في public_html

## تنظيم الكود

- `src/game/cases.ts` — كل محتوى القضية: المقدمة، المشتبه فيهم، الأدلة، نصوص الفوز والخسارة. تقدري تعدلي الأرقام والنصوص من هنا.
- `src/game/engine.ts` — منطق اللعبة: التايمر، جدول الأدلة، الخصم، الحفظ والاستكمال. أرقام الجولة في `DEFAULT_SETTINGS` (المدة ١٨٠ ثانية، دليل كل ٢٥ ثانية، خصم الاتهام الغلط ٢٠ ثانية) — أرقام أولية قابلة للتعديل بعد التجربة.
- `src/game/audio.ts` — الموسيقى والمؤثرات (WebAudio مولّدة، من غير ملفات صوت ولا حقوق نشر).
- `src/components/` — الشاشات: الدخول، الأرشيف، اللعب، النتيجة، والهيكل العام.
- `src/photos/` — الصور محلية جوه المشروع (بتنشتغل بعد النشر من غير روابط خارجية).

## ملاحظات

- شاشة الدخول شكلية (ديكور): مفيش بيانات بتتبعت أو بتتخزن.
- التقدّم بيتحفظ في المتصفح (localStorage): لو قفلتي الصفحة نص جولة، بترجعي تكملي من مكانك.
- فيه دعم تقليل الحركة (prefers-reduced-motion) لمن يفضّل أنيميشن أقل.
- صور الشخصيات توضيحية مولّدة بالذكاء الاصطناعي.
